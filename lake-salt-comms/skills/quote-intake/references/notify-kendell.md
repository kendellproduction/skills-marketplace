# Notify Kendell

## Channel 1 — Email (default, headless-safe)

Use the active Gmail connection to send a short notification to the owner's own inbox. Prefix the subject or first line with `LAKE SALT:`. Prefer native Gmail; use Zapier Gmail only as the portable fallback. Include the client, event/status, required decision, and unavailable capabilities.

## Channel 2 — iMessage (optional, Mac + computer-use only)

If a connected Mac and computer-use are available, the existing Messages automation may be used as an optional enhancement. It is not available in Codex or plain cloud runs and must never be required; use email instead.
